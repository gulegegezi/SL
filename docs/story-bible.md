# 人生模拟器 · 故事圣经

> 这本册子回答的是「这个游戏在讲什么」，不是「怎么实现」。
> 实现细节见 [story-opening.md](story-opening.md)、[story-links.md](story-links.md)、[story-cutscenes.md](story-cutscenes.md)。

## 一句话

一个没有名字的普通人，在一个没有名字的小城，从出生到死亡，做很多次选择，最后成为某个人。

不是成为最有钱、最成功、最正确的人。是成为 **某个具体的人**。

## 这个故事在讲什么

它不打算回答「怎样活才算对」。

它想回答的是更小、更具体的问题：

- 你做过那么多选择，最后留下来的，是哪几个？
- 那些被你错过的人，后来怎么样了？
- 你有没有在某个深夜，想起一句当时没说出口的话？
- 你成为现在这个人，是因为你选了什么，还是因为你没选什么？

人生不是一道有标准答案的题。它更像一叠被反复折叠的纸：每一次选择都留下折痕，最后你看到的，是这些折痕组成的形状。

## 语气

- **第二人称「你」**，但旁白保持克制，不替玩家抒情。
- 幽默来自观察，不来自嘲笑。可以好笑，但不刻薄。
- 不评判玩家的选择。选了「不」的人，也值得一个好故事。
- 不强行煽情。真正的难过，往往写在很轻的句子里。
- 每个结果尽量落在**具体物件**上：半块橡皮、一袋煮鸡蛋、一盆快死的绿植、一架落了灰的旧琴、一张背面写着字的照片。
- 留白比解释重要。很多话，说到一半就够了。

## 世界

一个没有名字的小城。可能是南方，可能是中部，可能是任何一个有老小区、学校、菜市场、医院走廊和河堤的地方。

地图上有六个地方：

| 地方 | 叙事功能 |
| --- | --- |
| 家 | 出发与回来；饭桌、灯、旧相册 |
| 学校 | 被比较、被看见、第一次喜欢、第一次考砸 |
| 工作坊 | 谋生、体面、加班、被裁员、升职 |
| 菜园 | 慢下来的东西；种下去不一定有收成 |
| 小镇广场 | 朋友、邻居、闲话、广场舞 |
| 河畔 | 一个人待着；钓鱼、发呆、想事情 |

季节按年龄轮换：童年是春，少年是夏，成年是秋，晚年是冬。这是把一辈子压缩成一天的视觉写法。

钱、房子、工作、婚姻、孩子都是真实压力，但不是评分标准。它们只是让「你」这个人变得更具体。

## 主角

主角没有名字，没有预设性格，没有「命定」的才能。

- 出生地、家庭、体质、天赋是随机的；这些是起点，不是结局。
- 六维属性只是倾向，不是命运。智力低的人也可以活得很好，运气差的人也可以被人记住。
- 主角的性格由玩家一次次选择累积出来：标签、关系值、选择记忆，最后拼成一个「你」。
- 主角不是天选之人。这个故事不奖励「特别」，它关心「普通」。

## 配角

配角不是功能按钮。每个人都有自己的日子要过，只是恰好和你的人生交叉了一段。

### 妈妈

嘴硬心软。她的爱很少说出口，通常以食物、成绩单、收拾行李、病房走廊的形式出现。

- 关键物件：煮鸡蛋、成绩单、老相册。
- 关键台词：「考得不好没关系，下次再来。」「到了记得吃饭。」「没事，你回去睡吧。」
- 她不是完美的母亲。她会叹气，会抽走你枕头下的红包，会在家长会上沉默。

### 爸爸

沉默，修东西，假装看车轮胎。他的爱是行动，不是语言。

- 关键物件：旧自行车、后备箱、缴费单。
- 关键台词：「到了打电话。」「你长大了。」「人没事就行。」
- 他也会有撑不住的时候，只是不会让你看见。

### 同桌

那个把橡皮切成小块的人。你们分享过一块橡皮，后来他转学了，没有告别。

- 关键物件：半块橡皮、铁盒、玻璃弹珠。
- 关键台词：「这样就不容易丢了。」「是我。……我回来了，想见一面。」「一直想还你。」
- 这条线问的是：**你会不会为一个没有告别的人，留一个位置？**

### 老同学

多年不见，突然问你「要不要出来一起做点事」。他代表另一条没走的路。

- 关键物件：一碗面、项目计划、十碗面的约定。
- 关键台词：「不急，你想好了再说。」「缺，一直缺。」
- 这条线问的是：**你是在走自己的路，还是在走一条没被否定的路？**

### 领导 / 同事

工作里的关系。不是朋友，也不一定是敌人。有时候是一盆绿植，有时候是一句「做成了是应该的，做砸了要背锅」。

- 关键物件：工位上的绿植、项目、工牌。
- 这条线问的是：**你想成为什么样的大人？**

### 音乐老师 / 旧琴

那个把排练室钥匙给你的人。你可能只练了一个月，也可能练了一辈子。

- 关键物件：落灰的钢琴、旧琴谱、耳机、旧电子琴。
- 关键台词：「别把琴弄坏。」「你是这周第三个来租琴的成年人。前两个都放弃了。」
- 这条线问的是：**你为生活放下了什么，又有没有捡回来？**

### 伴侣 / 孩子

不是必选项。如果出现，是生活的重量，也是光。

- 关键物件：结婚照、儿童房、全家福。
- 他们不是用来「完成人生」的，而是让「你」的时间有了另一个人的刻度。

## 时间轴

| 阶段 | 年龄 | 叙事重点 |
| --- | --- | --- |
| 序章 | 0–1 岁 | 出生、被看见、抓周；家人如何看你 |
| 童年 | 1–12 岁 | 幼儿园、小学、第一份友谊、第一次撒谎、第一次考砸 |
| 少年 | 13–18 岁 | 分科、中考、高考、暗恋、毕业留言 |
| 青年 | 19–25 岁 | 离家、大学、第一份工作、租房、第一次相亲 |
| 成年 | 26–40 岁 | 升职、买房、结婚、生娃、父母生病、三十岁分岔 |
| 中年 | 41–60 岁 | 孩子长大、父母老去、身体报警、职业收束 |
| 晚年 | 61+ 岁 | 退休、旧友、旧琴、老照片、告别 |

## 四条关系线的叙事功能

### 同桌线：被记住的秘密

从一块橡皮开始，到一场没有告别的转学，再到多年后的电话和同学聚会。

它讲的是「被记住」：你替别人守过一个秘密，多年后那个人还记得。你也可能选择不走近，于是这条线就停在「忙」和「下次」。

### 父母线：他们也会老

从家长会后的沉默，到离家那天的煮鸡蛋，到病房走廊，再到老照片。

它讲的是「时间的方向」：你一直在往前走，他们一直在原地变老。你什么时候第一次意识到这件事？

### 职业线：那条没走的路

从分科表，到第一份工作，到三十岁的分岔，到退休前最后一个项目。

它讲的是「选择之后」：你选了理科/文科、接了/推了项目、创业/升职/观望。每条路都有代价，没有一条是标准答案。

### 爱好线：没有走完的路

从排练室，到下班后的两小时，到旧琴，到晚年舞台。

它讲的是「被放下又捡起来的东西」：你小时候想学琴，后来忙于生活，某一天又在街角听见有人弹琴。

## 选择的设计原则

1. **没有标准答案。** 每个选项都有代价，也都有它的道理。
2. **不惩罚温柔。** 选择陪伴、坦白、把伞给别人的人，不应该在数值上吃亏。
3. **不奖励功利。** 选择赚钱、升职、明哲保身的人，也不应该被写成坏人。
4. **结果要具体。** 不要写「你很后悔」，写「你把那块橡皮放回铁盒，合上时发出一声很轻的响」。
5. **关系值不是好感度。** 它是「愿不愿意再走近一步」。可以是负的，负的也有故事。
6. **隐藏选项是回报，不是门槛。** 只有曾经走近过的人，才会看到多出来的那一句。
7. **每个选择都要有回响。** 哪怕只是一句 `{choice:V01}` 的回忆，也要让玩家知道：你选过，世界记得。

## 结局哲学

结局不是「成功/失败」，是「你成为了谁」。

评级只是游戏化的总结，不是道德判断。一个一生普通、没房没车的人，也可能有一个很好的结局：有人记得他，有人在他走后翻他的相册。

最好的结局不是最有钱的那个，是 **有人愿意在你身边多坐一会儿** 的那个。

## 写作检查清单

写完一段剧情，问自己：

- [ ] 这段里有没有一个具体的物件？
- [ ] 有没有一句没说出口的话？
- [ ] 这个选择会不会让玩家停一下？
- [ ] 结果有没有回响到后面？
- [ ] 有没有在说教？
- [ ] 如果把名字遮住，这段话像不像「这个人」会说的？
