# 新剧情的 Godot 接入

打开本项目 `project.godot`，运行默认 `scenes/Main.tscn`。首页选择 **「折痕与歪楼 · 新剧情漫画人生」**；有书签时会出现 **「继续新剧情 · 上次的漫画书签」**。也可直接运行 `scenes/LifeComic.tscn` 开始新的一生。

剧情来源为 SL 的 `story` 分支提交 `bb639ff`：24 个年龄窗口事件、72 个选项、144 个随机结果、四档叙事、6 组突发与照护事件。全文见 [story-life-events.md](story-life-events.md)。本分支的数据包已由原生 GDScript 加载，无需安装 Python。

## 实际运行的内容

- `life_comic_run.gd`：年龄和前置记忆筛选、已发生事件去重、选项成本先结算再抽结果；叙事档位在开场和结果分别锁定。重按选项不会二次结算。
- 18–24 次普通事件抉择控制阅读节奏。跳过的年份仍逐年计算风险、NPC 状态和疾病变化；抉择数不是寿命，也不在出生时预定死亡年龄。
- 身体与心理健康分别计算；抽象程度只改变表达。四档为贴地写实、日常吐槽、脑内小剧场、宇宙级脑补。NPC 原话及实际后果不随视角改写。
- 检查可排除癌症或进入确诊与治疗；治疗可稳定、缓解或进展。事故、恢复后的生活调整、已见过人物的离世都有可选分镜，解决当前场景后才回到年龄池。疾病与风险数值是虚构游戏平衡。
- 年幼主角的成人式比喻作为心里字幕；照护安排有成人协助。关系状态和存活状态限制 NPC 出场，不为恋爱或团圆强行制造人物。
- `life_comic_pages.gd` 把剧情分镜接到既有 `ComicPage`、像素人物和全身动作系统：开场四格、结果三格，突发事件按内容调整；留白页位于底部，逐步填充。镜头、NPC 原话、内心与实际结果分格显示。
- 演出复用现有走动、递接、阅读、电话、书写等动作。英文细分动作会映射到这些已有动作；**本次没有给每个随机结果新绘专属逐帧动画**。新增毯子、相片、钥匙、鸡蛋等道具，避免不相关的替代物。

## 存档

新剧情单独保存为 `user://life_comic_v1.save`，不改写原版漫画存档。保存完整随机状态、当前未决/已决选项、已画页面、历史叙事档位、NPC 和记忆。原生 Variant 序列化保留 64 位随机状态，以临时文件写完后替换正式书签。读档后继续当前选择或结果页，不重抽结果。无效存档不被自动覆盖。

`story` 的 Python 参考和 Godot 使用不同随机实现，相同数字种子不保证跨语言相同人生；Godot 自己的存取档保证续接同一随机序列。

## 验证

用 Godot 4 运行 `test/life_comic_smoke.gd`：80 次完整人生、20 组仅视角不同的配对人生、原生存档往返、年龄窗口、NPC 存活、结果去重及尾声。`test/life_comic_ui_smoke.gd` 检查真实按钮到下一页、结果恢复及 360 像素窄屏；带 `-- --capture` 可输出本地画面预览。

旧版序章、人物联动、过场、小镇状态、漫画页测试同时保留。新入口是完整独立模式，原版长短篇入口仍可使用。
