# 人物行动与画面表现力

2026-10-22，分支 `animation`。本次将条漫中的行动从单张立绘和物件位移，扩展为动作关键姿势、手臂关节、物件接触和镜头配合。人生路线与选项效果沿用现有短篇系统。

## 查看

- F5：在主游戏中体验抓周递接、作品集阅读、手机通话、写字和乐队敲鼓；选项结果分镜也使用同一动作系统。
- 打开 `scenes/ActingLab.tscn` 后 F6：查看递接、翻阅、电话、写字、敲鼓、走路、挥手、坐下八类演出。可切换七个人生阶段及妈妈、朋友、老板示例，暂停或拖动时间轴，并切换减少动态。
- `docs/acting/`：八张原生预览截图与三张真实游戏截图，含 360px 手机宽度；截图为某一时刻，完整动作在 Godot 中播放。

## 动作怎样发生

标准动作约 2.4 秒：先起手、再靠近目标、完成接触和具体行动，最后收势。手和物件到达接触点后切换像素关键姿势，避免交叉淡化造成两张脸叠在一起。

| 行动 | 人物与画面的变化 |
| --- | --- |
| 递接 | NPC 伸手递出，主角转向物件并伸臂；拖放后物件靠近手边，手掌由张开转为握持 |
| 阅读 | 双手拿书、目光向下；接触后有短暂翻页，镜头轻推近 |
| 电话 | 从桌面拿起手机，经过手臂靠近阶段，再切到举至耳边的专用姿势，空闲手配合交谈 |
| 写字 / 画画 | 前倾伏案，一手按纸、一手持笔；书写区有小幅运动，笔迹随动作推进出现 |
| 敲鼓 | 肩—肘—腕两段手臂，两只鼓槌交替起落；击打位置有短促线条，鼓的点击区与画面位置一致 |
| 走路 | 六个年龄阶段使用全身帧与固定脚底锚点，约 7 fps 交替播放，配合进出场位移与落地阴影 |
| 挥手 / 坐下 / 点头 | 手腕摆动、屈肘、身体下移、短暂俯首，动作后停在稳定姿态 |

旁白补充天气时，同一人物的持物动作继续，不会重新从桌面拿起电话。写字后接离开台词时，纸笔接触会有最低展示时间，再进入走路。玩家可直接选择选项继续，动作不成为推进门槛。

强情绪仍保留现有哭、惊、怒等专用表情；身体动作不会统一覆盖这些表情。低动态模式直接展示收势姿态，关闭身体运动和镜头推近。完成的互动读档时也从收势姿态显示，不重复播放。

## 新动作资源

全部通过本会话**内置 image_gen** 生成，使用仓库现有 `assets/comic_city/lead.png`、`npc.png` 作身份和画风参考。没有使用 API/CLI 后备生成。

- `assets/comic_actions/lead.png`、`middle.png`、`npc.png`：13 个身份 × 4 个不同的身体姿势 = **52 个区域**。覆盖婴儿、童年、少年、青年、成年、中年、老年及六位 NPC。
- `assets/comic_actions/walk.png`：6 个年龄阶段 × 4 个全身走路帧 = **24 个区域**。
- `assets/comic_actions/prompts.json`、`walk-prompts.json`：原始提示词、参考文件与重试记录。主角首次输出缺少中年行，因此单独补绘中年。走路首次请求连接失败，重试仍使用内置工具。
- `regions.json`、`walk-regions.json`：Atlas 区域索引；`tools/index_comic_actions.py` 根据 alpha 主连通区域计算边界，排除相邻格的小碎片，不重绘、不修改原始 PNG。

这些是动作关键姿势与程序动作的结合，目前不是每个事件、每种表情都有完整手绘全身逐帧动画。专用全身走路帧覆盖主角的童年至老年；NPC 的本次新增重点是递接、阅读、电话和写字。

## 接入位置

`comic_motion.gd` 提供不消耗随机数的动作时间线、工作进度与最低动作展示时间；`comic_actor.gd` 统一绘制人物、身体姿势、手臂及走路。`comic_interaction.gd` 负责物件接触和双人演出，`comic_panel.gd` 同时把它们用于剧情文字和选择结果。

同一动作跨分句延续。交互按下完成后仍接收匹配的松开事件，避免把无对应按下的松开事件交给滚动容器。互动完成状态使用现有书签字段，故事随机序列不变。

## 验证

Godot 4.7.2：13 组回归测试通过，包括 76 个动作区域、动作阶段、书写进度、动作跨旁白延续、写字到离开的衔接、实际鼠标互动、鼓的点击区域、读档收势、窄屏阅读器、完整短篇/长篇人生、文字演出及旧序章/联动。错误日志为空。

`tools/capture_acting.gd` 导出演出预览，`tools/capture_acting_game.gd` 在真实主游戏中点击电话和鼓，检查动作启动并导出桌面及手机画面；真实用户存档写入关闭。
