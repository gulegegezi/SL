# 漫画分镜系统

> 当前可玩的存档版、成熟像素人物和纵向阅读规则见 [人生未完：漫画阅读器](life-comic-reader.md)。下文保留早期固定页原型的记录；旧版中年格数、固定排版和线稿生成方法不代表当前显示路径。

游戏进入人生后的主界面从「文字卡 + 选项按钮」改成**漫画页**：一岁一话，一话由若干格组成，
格子按镜别取景，格数随年龄增长，也会因健康与性格变化；有些年份会被「提笔带过」。

## 一、一页是怎么决定的

`scripts/comic_director.gd`（纯逻辑，不碰节点）：

```
格数 = 年龄基准(age)            # 童年 2 / 小学 2 / 少年 3 / 青年~成年 4 / 中年 3 / 晚年 2
     + 健康修正                 # 体质 ≤3 → -2，≤6 → -1，≥16 → +1
     + 性格修正                 # 外向标签 +1~+2，内向标签 -1~-2
     + 抽象加成                 # 抽象度 ≥61 时 +1
     + 本局随机偏移             # 每次存档固定随机 -1 / 0 / +1
     + 每页随机 0~1
     然后夹到 2~6 格
```

- **年龄**决定基准：人生越往后，一页能塞的镜头越多（成年最多 4 格起）。
- **健康**是真的会压缩分镜：身体不行，人生就没有那么多镜头。
- **性格**来自选择累积的标签（`会分享 / 仗义 / 勇敢` vs `守口如瓶 / 观察者`）。
- **每局随机**用 `±1 格偏移`而不是倍率 —— 用倍率会把年龄曲线压平（早期版本踩过）。

`should_montage()` 决定这一岁要不要「提笔带过」，概率受年龄阶段与健康影响；
开局前两页强制不跳，且**要攒够两年才合成一页**，避免每页都在略过。

## 二、版式与镜别

`LAYOUTS` 里按格数分 1~6 格共 10 套版式（归一化坐标），例如 3 格有「上宽下分」和
「左竖右侧分」两种。格与格之间留 5px 缝，每格再随机旋转 ±0.9°，读起来像手工贴上去的。

镜别（`_shot`）：

| 镜别 | 用法 | 定位方式 |
|---|---|---|
| `wide` | 第 0 格，交代环境 | 脚贴格底，占格高 72% |
| `medium` | 中段 | 脚贴格底，占格高 98% |
| `close` | 信息格 | **头顶贴格顶**，放大 1.42 倍 |
| `extreme` | 末格，情绪 | 头顶贴格顶，放大 2.1 倍 |
| `detail` | 空镜/物件 | 不画人，只排线 |

特写必须按「头顶贴顶」放：全按脚贴底算，一放大头就被推到格子上方外面，只剩一片头发。

## 三、页面绘制

`scripts/comic_page.gd`（页眉/版式/页脚） + `scripts/comic_panel.gd`（单格）：

- 页眉：黑条 `第 N 话 · 岁 · 阶段`，右侧 `全 X 话`（X = 寿命）
- 单格：底色（纸 / 网点 / 全黑）→ 角色线稿 → 旁白框 / 气泡 / 拟声词 → 墨框
- 墨框用带抖动的折线画，不用 `draw_rect`，避免机械感
- 全页只允许一格纯黑（高潮格），黑格里**不画角色**，只放速度线与居中白字
- 旁白固定在格子下沿（角色头部永远在格子上方，压上面必定盖脸）

## 四、角色线稿

`_make_ink_art.py`（工作区脚本）把 `assets/portraits_v2` 的角色帧转成墨线 + 网点：

1. 裁原始帧 → 超采样 2.5 倍
2. 中值滤波去噪 → 高斯模糊 → `FIND_EDGES` → 阈值 → 膨胀 1px 得墨线
3. 亮度分三档：亮部留白 / 中间调网点 / 暗部实心墨
4. 按原 alpha 剪影裁切，边缘加 0.6px 模糊去锯齿
5. 输出 `assets/ink/<角色>_<帧>.png`（384 高）与 `tone.png` / `paper.png`

重新生成：

```bash
python _make_ink_art.py          # 在仓库根目录的上一级（工作区）执行
godot --headless --path . --import
```

## 五、页与页之间

| 页面 | 触发 | 内容 |
|---|---|---|
| 正片 | 普通一岁 | 本话 = 这一岁的事件，格数按上表 |
| 结果页 | 选完之后 | 三格：动作 / 结果特写 / 数值变化 |
| 提笔带过 | 攒够两年被跳过 | 两格：黑底大字 + 结果旁白 |
