## 一、它的六个手法

| 手法 | 具体做法 |
| --- | --- |
| **信息不对称** | 每个角色只掌握一半信息，然后按自己的理解行动；观众知道得比角色多，笑点来自落差 |
| **误会加码** | 解释不但没解开，反而让误会升级；每轮至少加一层，从不原地打转 |
| **游戏脑比喻** | 把关系当游戏机制讲（仇恨值、旗标、掉率、队伍配置），是自嘲，不是炫技 |
| **自 awareness** | 角色和旁白都知道"这局面太离谱"，甚至会画关系图，但画完更乱 |
| **多视角** | 同一件事，每个人讲出来是不同版本，谁也不觉得自己错 |
| **温柔底色** | 没有人真的坏，最后靠一句诚实的小话解开，而不是靠大吵一架 |

## 二、落到本作：`misread` 字段

新增一个可选字段，写在事件上：

```json
"misread": "邻居认定你在约会；同事以为你被邻居催婚；你以为自己只是打了个排位。"
```

页面生成时（`life_comic_pages.make`）会在结尾加一格旁白：

> 旁白：误会：邻居认定你在约会；同事以为你被邻居催婚；你以为自己只是打了个排位。

这样读者能同时看到三个版本，正是电波系的核心快感——**不是角色蠢，是信息不完整**。

## 三、新事件 LC34

**联机到十点，被邻居误会在相亲**（23–32 岁）

> 邻居：年轻人，慢慢聊。
> 同事：她为什么笑得那么懂？
> 你：可能误会了。
> 同事：误会什么？
> 你：误会我们在约会。

三个选项都是"误会加码"而不是"解决误会"：

1. **追出去解释** → 传闻从"约会"升级成"同居"；
2. **不解释，继续打** → 楼下大爷开始问"对象呢"；
3. **干脆请同事吃顿饭** → 邻居点头"进展不错"，用一个更大的误会盖住上一个。

每个选项都带旁白吐槽，例如：

> 旁白：你解释了十分钟，误会从"约会"升级成"同居"。

## 六、还没做的

- 误会目前是**单向展示**（旁白告诉你三个人各怎么想），还没有做成"随选择累积的误会值"。
- 没有多视角重复同一场景（电波系常见的"同一晚三个版本"），这需要页面级的多 POV 结构。
- 游戏梗停留在"排位/团建"级别，没有更深的机制玩笑。
