# 从立绘分镜到像素剧情场景

2026-10-22，`animation` 分支。主游戏中的已发生分镜，只要有角色，默认使用场景演出；未来空格和纯文字的跨年/数值结算格仍保留条漫形式。没有改选项效果、人生事件数量或旧存档格式。

## 玩家看到的变化

- 主角以全身出现在房间中，年龄阶段和走路帧分别保留。人物根据分镜高度自适应大小，360 像素窄屏也能看清。
- NPC 有独立站位与回应：递物、挥手、演出观众、照料时靠近。台词的说话人为 NPC 时，其动作交给 NPC，主角不再代演。
- 场景分为工作、学习、照料、吃饭、上台、告别、递物与交谈。桌椅、门窗、显示器、书本、药品、餐食、行李和前景遮挡共同交代事件。
- 打字时屏幕显示内容，关机后屏幕变暗；食物冒热气；敲鼓时有鼓槌和音符；离开时主角走出画面，朋友留在原地。电话以分屏交代另一端的人。
- 点按/拖动/长按仍可略过。完成互动后，道具从可点击区域移动到人物手边；敲鼓和手机互动继续使用原有命中区域与存档记录。
- 强烈反应保留小幅表情特写，让它成为场景的一部分。历史页直接显示收势结果；减少动态模式不重复播放入场。

## 实现

`scripts/comic_world.gd` 负责场景计划、角色像素采样、多人站位、物件演出和环境结果。`comic_panel.gd` 复用原有逐句导演和计时器，在主游戏、选项结果和历史页共用这个渲染器。指定 `presentation: "portrait"` 仍可选择旧演出。

像素化是运行时渲染采样：保留现有素材文件，将全身角色按 64 像素高度、NPC 上身按 28 像素高度采样、缩减调色板，再以最近邻放大；NPC 身体和手臂、道具、场景前景以代码绘制。Atlas 的像素缓存按资源实例区分，避免同一原图上的不同年龄、角色与走路帧被错误复用。本次没有引入第三方游戏角色或素材。

还修正了 Godot 在 `add_child()` 时自动开启 `_process` 导致历史分镜重新计时的问题：进入场景树后按已准备的揭示/互动状态恢复处理开关。

## 预览与验证

- F5：主游戏。
- 打开 `scenes/WorldLab.tscn` 后 F6：六组连续三格场景，可选择加班、演出、借书、回家、体检、告别；支持播放、暂停和时间滑杆。
- `test/comic_world_smoke.gd`：角色 Atlas 缓存身份、年龄差异、走路帧差异、六组场景、历史与减少动态。
- 本次共通过 14 组回归，覆盖逐句演出、真实鼠标互动、选项只结算一次、存档恢复、360 像素阅读器、短篇与旧版长线整局流程。
- `tools/capture_world.gd` 生成六组原生 Godot 画面和告别收势；`tools/capture_acting_game.gd -- --world` 生成主游戏点击手机/鼓与窄屏截图，保存于 `docs/world-scenes/`。捕获过程关闭存档写入。

这是可运行的场景演出扩展。六组手动预览用于展示连续叙事；其余人生事件由场景计划和现有逐句导演组合演出，尚未逐条制作独有的手绘动画。
