# 剧情体检与「串」：梗、回响、一致性

> 对 `data/story_life_comic.json` 做了一轮体检：25 个事件、每个 4 档镜头、3 个选项。
> 结论是结构没问题、冷幽默的底子在；缺的是**前后不串**——每段都好笑，但笑完就完了。
> 这次补了 6 条贯穿线 + 6 个新梗，并留下一个可重跑的检查工具。

## 一、检查什么

`tools/check_story.py` 会逐条检查：

| 项 | 规则 |
| --- | --- |
| 结构 | id 唯一、有标题、`age_range` 合法、3 个选项、4 档 lenses |
| 文本 | 旁白 ≤90 字、内心 ≤70、台词 ≤50、收尾 ≤70（渲染换行友好） |
| 回响 | `echo.from` 必须存在，且比本事件更早 |
| 串线 | `motifs[*].events` 里的 id 必须都存在，每条至少串两处 |
| 重复 | 统计旁白开头 8 字，连续 4 次以上会报出来 |

跑法：

```bash
python tools/check_story.py
# 事件 25 条；回响 6 处；motif 6 个
# 旁白/内心总字数 3965
# 结论：通过
```
