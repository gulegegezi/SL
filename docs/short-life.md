# 人生短篇：少一些回合，多一些值得记住的事

2026-10-22，开发及提交分支：`animation`。本次按用户明确要求，同时调整事件线、共享控制器与漫画交互；不合回 master。原版事件池和旧书签保留，标题页可选择原版长篇。

## 一局的流程

新开局默认短篇：出生掷骰 → 关键事件 → 可选分镜互动 → 三选一 → 动作与结果镜头 → 跨过日常年份 → 下一个关键事件 → 结局。通常约 14–20 次抉择；健康和寿命不足可更早结束。

年龄锚点是 1、4、7、12、16、18、22、27、33、40、48、56、65、74、84、94 岁。跳过的是重复日常，不会在后台随机替玩家选择。18 岁选择先工作会直接跳到 27 岁，省略求学及校招段；过场交代学徒与攒钱的生活。

关键转折有同龄后续：把画留在纸上、乐队首演、朋友合伙、体检复查。后续先播完，年龄才继续推进。健康选择可增减体质和寿命；跨过的衰老阈值会结算，最后一个年龄点也不会陷入重复事件。

## 内容与选择的回响

`data/short_life.json` 共有 **20 个主事件变体、4 个同龄后续、72 个选项**。每个事件有场景铺垫、具体动作、抉择三格；每个选项有至少两个动作/结果镜头，完整保留结果文字。

| 人生阶段 | 事件与趣味 | 选择的后续 |
| --- | --- | --- |
| 婴幼儿 | 抓周时找玩具、墙上的第一届画展 | 恋家、好奇、画画；纸上画展的同龄后续 |
| 少年 | 半块橡皮、成绩单或班费失踪案 | 老友、认真、幽默；不同特征进入不同事件 |
| 青年 | 社团首演、志愿表、应届生招聘或画稿报价 | 乐队、画画、手艺路线；离乡或跳过求学 |
| 成年 | 深夜消息、续租谈判、体检或老乐队重聚 | 关系、边界、健康风险、复查后续 |
| 中晚年 | 妈妈撤回语音、旧纸箱、退休或社区音乐节 | 回看童年选择；爱好和关系再次出现 |
| 晚年 | 药盒、给未来的信、长椅上的午后 | 主动求助、分享、释然，直到健康或寿命终章 |

画画与乐队标签提高对应后续出现的机会，而不是强制每局走同一条线。56 岁的纸箱会引用玩家 4 岁时的真实选择；84 岁还能再次画八条腿的太阳。幽默来自具体处境和回响，文字均为本项目新写。

## 分镜互动与动画

互动格使用现有成熟像素立绘、青绿环境和独立道具，避免每个事件都画同一张脸。四种输入是点击、拖到框内、按住约 0.8 秒、翻开纸页：

- 抓周拖玩具、同桌递橡皮，物件移向主角的手边。
- 敲练习鼓有短暂鼓槌动作和反应；点电话将手机移近人物，并出现通话反馈。
- 翻成绩单、账本、合同、相册或报告，显示与剧情相关的小细节。
- 按住读完语音或查看纸页，短按中断后可重试。

互动不自动选择剧情、不发放可重复刷取的属性，也不会锁住下方选项。每格完成一次；完成状态进入书签，尺寸重排或读档后不重置。选择完成后过去的互动格冻结，完结书架仅供回看。

动画仍以立绘、道具和手势组合为主，并非每镜头都已有全身逐帧动画。结果第一格由剧本明确指定动作和表情，反应格按实际句子识别人物；例如主角讲作品后，下一格由老板点头。

## 技术与兼容

- `short_life.gd`：年龄锚点、标签变体与跳年过场。`short_target_age` 支持明确选择跳过某个人生段。
- `short_storyboard.gd`：读取人工编排的漫画格，不再为短篇随机塞空白表情格；结果镜头继承事件地点。
- `comic_interaction.gd` / `comic_objects.gd`：可点击/拖动对象、短动作与道具画法。
- `ComicPanel → ComicPage → main`：互动信号更新历史分镜，再进入原有原子书签保存。
- `GameState.short_mode` 缺省 false，因此旧存档继续原流程；控制器的新开局缺省开启短篇。
- 作者源在 `tools/build_short_life.py`；修改后运行生成 JSON。它只整理文字与剧本结构，不生成或修改美术 PNG。

## 验证与截图

`short_life_smoke.gd` 校验所有剧本、72 个选项、24 条完整人生、同龄分支、跳过求学、选择记忆与旧档默认值。固定测试路线需要 14–17 次抉择。

`comic_interaction_smoke.gd` 通过真实鼠标输入验证四类互动、取消重试、只完成一次、尺寸重排、历史记录与存档恢复。`short_reader_life_cycle.gd` 不做任何互动也能通关，并在结果页存档恢复后继续：两条路线分别为 16 次/92 岁和 14 次/88 岁。

原有阅读器、完整长篇人生、文字演出、过场、序章和联动回归继续保留。原生 Godot 截图在 `docs/short-life/`，包括互动前后、结果页、360px 阅读器和 18→27 岁跳年。

最终验证：2026-10-22，Godot 4.7.2，共 12 组回归全部通过且错误日志为空。11 张原生截图已检查；运行测试和截图时关闭真实存档写入，测试书签使用独立路径并在结束后清理。
