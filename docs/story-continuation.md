## 旁白三句法

每个四档镜头都按同一个节奏写：

1. **设定**（把荒诞当正常）：「毕业照项目进入表情招标阶段，标书要求：像知道未来。」
2. **元吐槽**（旁白知道这是游戏）：「作文评分标准里没有“玩家”。旁白查了一下，也没有“旁白”。」
3. **具体物件**（笑点落在东西上）：「系统里 128 个专业，没有“再想想”。」「这张以后会出现在家庭群，配文“我们家的乖崽”。」

选项后的旁白也照这个来：

- 「老师犹豫了三秒。旁白：那三秒，是这张照片最值钱的部分。」
- 「系统卡了三秒。旁白：那三秒它在读你的理由，还是在读你的胆子？」
- 「老师看了很久。旁白：她可能第一次见到有作者给自己的作文写免责声明。」

## 结构

每个事件都完整带：

- `facts` / `npc_dialogue`（首页与气泡）
- `lenses[4]`（四档：旁白 / 内心 / 台词 / 收尾）
- `choices[3]`，每个带 `lines[4]`、`outcomes`（四档 `voices` + 结果页三格）
- `panels[4]`（建立 / 看道具 / 反应 / 选择停顿）
- `narrator_asides[4]`（给以后做“旁白弹幕”留的）

生成脚本：`tools/add_story_events.py`（可重跑，已存在会拒绝重复写入）。

## 验证

## 限制

- 新事件还没有专属 CG 与场景互动（`pixel_cg` / `pixel_interaction`），走的是普通漫画页。
- `narrator_asides` 目前没有渲染方，属于给下一步“旁白弹幕/括号吐槽”预留的数据。
- 三个事件都是 `once`，不会重复出现。
