# 对话手法：学的是「怎么写台词」，不是剧情结构

> 澄清：这次不学《GAMERS 电玩咖》的误会网结构，只学**它的对话手感**——
> 怎么用短句、抢拍、错位、复读和吐槽，把一段日常写得有来有回。
> 下列所有台词都是本作原创，没有复制原作文本。

## 一、六条手法

| 手法 | 做法 | 本作例子 |
| --- | --- | --- |
| **短句抢拍** | 一句只做一件事，砍掉“我觉得”“其实”“然后” | 「你：今天不想补。」「医生：那也得知道补什么。」 |
| **答非所问** | 用另一个问题的答案，暴露说话人真正在意的事 | 「你：电费单在桌上。」「对方：可以当餐垫。」 |
| **抓词复读** | 抓住对方一个词，反着用回去 | 「你：面子能用橡皮撑？」「同桌：能，先用你的。」 |
| **术语落地** | 把工作/游戏词塞进生活对话，制造错位 | 「同事：它没写 deadline。」「你：它有叶子。」 |
| **内心错位** | 心里想的和嘴上说的相反（在四档镜头里成对写） | 嘴上「这真是同事」，心里「她送的是苹果，收走的是我的清白」 |
| **收尾吐槽** | 最后一句短、狠、把前面的话戳破 | 「你：她信了？」「同事：笑得更懂了。」 |

## 二、节奏

- 一段 **4–7 拍**，每 2–3 拍给一个小反转；
- 问句是节拍器：一段里至少一个「？」，用问句推进而不是用叙述推进；
- 结尾一句尽量 ≤ 10 字（「早说。」「让他抢。」「笑得更懂了。」）。

## 四、写进数据的方式

- 每行一句「名字：台词」，靠 `npc_lines` 解析成对白格；
- 四档镜头里的 `inner` 与 `dialogue` 成对写，制造“表里不一”；
- 所有台词都不写舞台指示，动作交给立绘和面板。

## 五·四、标点停顿与句内加速

逐字延迟（`comic_panel.char_delay`）：

| 字符 | 基础延迟 | 额外停顿 | 读感 |
| --- | --- | --- | --- |
| 普通字 | 0.025s | — | 正常 |
| 逗号 / 顿号 | 0.10s | — | 换气 |
| 句号 / 叹号 / 问号 | 0.22s | — | 落点 |
| 省略号 `…` | 0.10s | **+0.16s** | 迟疑 |
| 破折号 `—` | 0.05s | **+0.28s** | 被打断/拖长 |

**句内加速**：连续出现「！」「？」时，后续字的速度每次乘 0.92，最低到 0.72；
遇到句号复位。所以一段越说越急的台词会自己加速，不用手写标记。

## 五·五、语速与抢话（已实现）

**角色语速表**（`comic_panel.cadence_for`）——同一句话，不同人打出来的速度不同：

| 角色 | 倍率 | 读感 |
| --- | --- | --- |
| 你 / 我 | 0.7 | 快，像抢着说 |
| 同桌 / 同学 | 0.85 | 略快 |
| 老师 / 室友 | 1.0 | 标准 |
| 同事 / 销售 / 对方 | 1.05–1.1 | 略慢 |
| 妈妈 | 1.15 | 稳 |
| 医生 | 1.25 | 慢而清楚 |
| 爸爸 / 班长 | 1.4–1.45 | 慢，像在斟酌 |
| 身边的熟人 / 熟人 | 1.5 | 最慢，像在回忆 |

**情绪叠加**（`cadence_for(speaker, expr)`）：同一角色，生气时更快、哭/累时更慢：

| 情绪 | 倍率 |
| --- | --- |
| rage | 0.70 |
| angry / panic / scared | 0.70–0.75 |
| shock / surprise | 0.80–0.85 |
| happy / smile | 0.90 |
| 默认 | 1.00 |
| sad | 1.30 |
| cry / tired | 1.35 |
| sleep | 1.40 |

**抢话标记**：句尾是「——」或「……」时，正文末尾自动补一个 `▍`，
读起来就是话没说完被打断。例如：

> 你：她可能以为……

显示为：

> 你：她可能以为▍

回归测试：

```bash
godot --headless --path . --script res://test/dialogue_rhythm_smoke.gd
# PASS: speaker cadence and interruption marker helpers
```

## 六、没做的

- 抢话只有 `▍` 文本标记，还没有“气泡被切掉一角”的视觉；
- 没有按角色做口癖表（现在靠用词区分：爸爸“我自己来”、妈妈“先……再说”、老师“算/不算”）；
- 语速只按说话人区分，没有按情绪（生气/犹豫）变化。
