gamelife · 星露谷风 UI 动画

按手绘模板把主界面切成四个区域，每个区域配一套语义相符的动画。此页是按 Godot 侧同一套参数复刻的可视化预览（本机无法启动 Godot，故用网页呈现效果）。

预览用网页实现，与 Godot 的 scripts/ui_anim.gd 一一对应（同样的色板、同样的时序与缓动）。

① 数值区

6 张属性卡依次弹入（BACK 过冲）
数字从旧值滚动到新值（CUBIC + 落定回弹）
旁侧「+3 / -2」闪烁后淡出
抽象度条按比例生长 + 数值同步滚动

② 事件区

木牌纵向展开落地（BACK 过冲）+ 落地横晃
正文逐字打字机（约 56 字/秒）
页脚常驻飘叶（循环）

③ 选项区

按钮错峰弹入
悬浮抬升 1.035 / 按下下沉 0.972
选中：暖色闪光 + ✔ 章印拍下

④ 演出区

深色土槽 + 木框 + 四角木钉
暖色光点四散 + 微光粒上浮
按本次选择的特征播放对应像素动画

背景 一辈子 = 一天

天空渐变色板随时辰插值
太阳沿弧线升落，入夜换月牙
山丘 / 草地 / 栅栏随夜色压暗偏蓝
云缓慢横移，夜间萤火亮起
