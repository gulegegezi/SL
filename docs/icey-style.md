## 二、学到的语言风格（原句）

| 手法 | 原文 |
| --- | --- |
| 旁白有名字、有立场 | 「艾希，请向右前进，消灭迷路机械蜘蛛，寻找终极核心。」 |
| 玩家违抗 → 旁白惊讶 | 「你真的跳下去了？那是悬崖，不是隐藏关卡！」 |
| 再违抗 → 阴阳 | 「第二次。很好。我的剧本现在比你的血条还短。」 |
| 三次 → 破防 + 成就 | 「【成就达成：真正的逆反心理】旁白君当场破防，并向你投掷了众筹 1100 万的支票……是道具！不许兑现！」 |
| 元层级（剧本当对象） | 「剧本说你应该服从。可你偏偏把剧本也切开了。」 |
| 系统语言当台词 | 「意识重构 / CHECKPOINT RESTORED」 |
| 冷幽默靠具体数字 | 1100 万、血条、三秒、14 组测试 |
| 结局承认玩家行为 | 「真正的自由，是不按剧本。」 |

## 三、提炼成六条可执行规则

1. **旁白是一个角色**：有名字、有情绪、会威胁、会自嘲，不是说明书。
2. **违抗要有回馈，而且逐次升级**：惊讶 → 阴阳 → 破防，每次都给新东西（成就/隐藏房间）。
3. **元叙述必须具体**：说「剧本」「台词」「存档」「成就」，不要泛泛说「命运」。
4. **笑点落在具体数字或道具上**：1100 万的支票、比血条还短的剧本。
5. **系统提示可以当台词**：CHECKPOINT、成就框、众筹金额，都能塞进叙事。
6. **结局要认账**：玩家怎么玩，结尾就怎么称呼这次游玩。

## 四、落到本作

本作是人生模拟，不是动作游戏，所以不搬它的战斗梗；搬的是**旁白的自我意识**和**违抗的回馈**。

上一轮已经改了 `facts`（开场旁白）和 `guide`（选项前旁白）；这一轮把 **LC01–LC09 的 27 条 `responses`（选择之后的旁白）**全部改成旁白视角：

| 选择 | 改后 |
| --- | --- |
| LC01 继续抓毯角 | 行，不松。剧本上写的是「松开手，开始认识世界」——但剧本没长手，你有。 |
| LC03 用手影演兔子 | 你给黑暗加了个节目。旁白原安排的是「全家惊慌」，现在改成「家庭手影秀」。 |
| LC04 请老师回来 | 你请老师回来。旁白准备好的「儿童法庭大戏」，临时改成「等大人」。 |
| LC06 收下橡皮 | 你也分了一半。旁白记下：本作第一个双向绑定道具。 |
| LC08 先吃饭再看卷子 | 你先照顾今天的自己。旁白批准了碳水补给。 |
| LC09 不上台但预约排练 | 你没上台，但留了下一次。旁白把这段存档为「待续」。 |

原则：**梗只挂在旁白身上，人物的内心仍然认真**——这样既有元叙述的乐子，也不毁掉人生模拟的诚恳。
