## 文字怎样变成演出

`comic_performance.gd` 是确定性中文规则导演，不调用在线模型。按标点分句，以动作或情绪词在原文中的位置触发表演，不在未来台词出现前先哭或先笑。

1. 找到人物、动作、情绪与道具。识别“妈妈对你挥手”和“你给妈妈打电话”的不同主语；父亲使用现有男性 NPC 形象。
2. 排除附近的否定词及简单假设：“没有哭”“笑不出来”“如果你哭了”不触发哭笑。转折后更新表情，不永久保留前一句笑容。
3. 同一人物的道具与动作在相邻句间延续：“拿起手机，窗外下雨”保留手机；“放下/挂断”结束。睡着后不因天气旁白而睁眼。
4. 文字、表情和动作同拍推进，标点停顿；强情绪短暂蓄势，再集中线、反应特写和轻微位移。每格最多一次冲击，避免重复闪动。
5. 签字、电话、读书、电脑切到对应物件；走出画面有位移；安静与否定段落不套用无关拟声词。雨衣不等于下雨，车停不等于雨停。

静态旧页直接显示最终表情和全文，不重新播放冲击。演出不使用人生随机数、不改变原文、选项、分镜数量和游戏状态。旧存档即使没有 performance 字段也能在加载时推导演出。

同步旧过场时还修复了动作 target 与表情 face 分离、主角帧索引缺少 lead_ 前缀，以及 V13 父亲沿用母亲外形的问题。运行时角色动作写入舞台自己的数据副本，不污染加载器中的剧情模板。

## 美术与漫画节奏

沿用青绿环境、暗色轮廓、红色强调与较成熟人物比例，新增 13 人物阶段 × 6 表情 = **78 个独立表情区域**：笑、哭、怒、惊、慌、闭眼睡眠。7 个人生阶段（婴儿至老年）及 6 位 NPC；中年单独补图以保持灰鬓、眼镜和服装阶段。

图片由本会话内置 imagegen 生成，原始 PNG、提示词与参考说明在 `assets/comic_expressions/`。`tools/index_comic_expressions.py` 仅按单元格 alpha 边界建立 Atlas 索引，不重绘或修改图像。nearest 采样保留像素边缘。

漫画阅读参考了 [Clip Studio 官方漫画叙事教程](https://www.clipstudio.net/en/comics-manga/design-tips/)：铺垫、动作、反应的顺序，关键情绪推近，以及以重要物件补足对白信息。本实现把这些原则用于逐字停顿、情绪镜别和道具特写；并非每句话都添加夸张效果。

## 手工导演覆盖

单格可选 `expr`、`action`、`actor`、`prop`、`intensity`、`weather`，显式字段优先于推断；`shot_locked: true` 保留作者选定的镜别。例如：

```json
{"caption":"妈妈把信推到你面前。","ink":"lead_adult","actor":"parent","expr":"sad","action":"raise","intensity":0,"shot":"close","shot_locked":true}
```

演员：lead / parent / friend / teacher / boss / partner / mate。低动态预览关闭闪白、震动和反应插框。

## 边界

这是规则驱动演出，复杂指代、反讽、隐喻和多人同句仍应手工标注。新立绘有六个独立表情；害羞、疼痛、坚定等暂复用原担忧姿势，爱意/得意复用笑容，尚非每种情绪都单独绘制。祖母复用现有女性家人角色。

动作使用立绘位移、符号手势与程序绘制道具，睡眠为闭眼立绘和被褥构图；尚非逐镜头手绘全身动画。后续可按剧情高频事件补完整手部和全身关键帧。
