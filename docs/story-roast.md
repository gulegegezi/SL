# 选择回应与吐槽：前 30 年的润色

> 目标：**每个选项都有自己的回应；选得太离谱，旁白会当场吐槽。**
> 吐槽是可选的 `roast` 字段，挂在具体选项上，只在结果页追加一句。

## 一、机制

```json
"choices": [
  { "label": "用手影给大人演一只兔子",
    "roast": "旁白：停电五分钟，你办了一场个人演出。",
    "effects": { ... }, "lines": [ ... ], "outcomes": [ ... ] }
]
```

结果页组装时（`life_comic_pages.make`）：

```gdscript
var roast := str(c.get("roast", "")).strip_edges()
if not roast.is_empty():
    response += "\n" + roast
```

所以：**普通选项 = 贴合它的回应；离谱选项 = 回应 + 吐槽**。
吐槽只影响一句话，不改数值、不影响分支。

## 三、回应润色（前 30 年）

| 范围 | 改了什么 |
| --- | --- |
| LC01–LC09 | 27 条 responses 改成旁白视角（上一轮完成） |
| **LC10–LC18** | 27 条 responses 全部重写：先贴合这个选择，再补一句旁白 |
| LC26–LC28 | 生成时已带「贴合选择 + 旁白」的回应 |

例子（LC14 借钱）：

- 借一部分 →「你借了能承担的部分，也写清安排。旁白：量力而行，不是打折的友情。」
- 不借但陪他想办法 →「你没借钱，但陪他列办法。旁白：救生圈不一定用钱做。」
- 明确拒绝 →「你也在困难里，明确拒绝。旁白：余额不够的时候，诚实最省利息。」

## 四、验证

```bash
python tools/check_story.py

# PASS: 9 choice roasts, roast reaches the result page
godot --headless --path . --script res://test/story_tone_smoke.gd

```

`story_roast_smoke` 做两件事：确认至少有 6 个离谱选项带吐槽；
再用 LC03 的「手影兔子」跑一次结算，断言结果页里出现「个人演出」。

## 五、没做的

- 吐槽不做运行时判定（比如「属性变化太极端」才触发）——目前是作者手动标注，更可控。
- 同一个选项只有一个吐槽，没有按档位（抽象度）变化。
- 吐槽只出现在结果页，不出现在选择页。
