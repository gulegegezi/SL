# 漫画里的 3D 像素舞台

> 后续更正：按用户提供的新参考，主游戏已改为 **3D 场景 + 2D 像素人物**。下文的体素人物说明属于上一版记录；当前角色实现和限制见 [二维人物接入说明](hd2d-characters.md)。

新剧情漫画人生的角色和背景现在放在同一个 Godot 3D 空间中：人物有身体体积、关节动作和落地位置，家具、墙壁、树木会参与遮挡与光照。漫画仍然向下阅读，人物对白和旁白继续分开呈现；每个可见分镜显示自己的微缩场景。

![Godot 实际运行：人物接过鸡蛋袋](pixel-stage-3d-preview.png)

这一版本接入 `animation` 分支的「折痕与歪楼 · 新剧情漫画人生」。原生 3D 舞台使用 `pixel_actor_3d.gd`、`pixel_environment_3d.gd` 和 `pixel_stage_view.gd`，由 `life_comic_pages.gd` 生成的 `presentation: pixel3d` 分镜启用。

## 进入与操作

### 技术与美术参考（2026-10-24）

用户追加的方向是 t3ssel8r 的 3D 像素技术感、《风来之国》的生活色彩与环境细节，以及《八方旅人》的空间光影。此版本是原创 Godot 实现，不包含这些作品的模型、贴图或专有渲染代码，也不声称已复现其完整管线。

- 实际立体网格和正交相机；画面按整数倍放大，避免一列像素粗、一列细。
- 相机对齐视平面的像素网格，再把取整余量补回显示位置，改善平移时的像素游动；旋转和缩放仍需重新投影，并非所有运动都无闪烁。
- `shaders/pixel_grade.gdshader` 仅作用于场景：轻度明暗分级、青蓝暗部、暖色亮部、亮度边缘强化与小范围高光扩散。它是 Compatibility 可用的颜色后处理，并非深度／法线凸边描线或体积光。
- 主角与 NPC 共用调色逻辑，前景花盆、中景人物、远景窗户与家具靠真实遮挡和投影分层。手持道具新增书页、屏幕、照片、鸡蛋袋、钥匙齿等形状，家具型道具不会被吸到手上。

参考：[t3ssel8r 公开作品](https://www.youtube.com/@t3ssel8r)、[David Holland 的 Godot 3D 像素渲染实践](https://www.davidhol.land/articles/3d-pixel-art-rendering/)、[Eastward 官方画面](https://eastwardgame.com/media/)、[OCTOPATH TRAVELER 官方 HD-2D 介绍](https://www.jp.square-enix.com/octopathtraveler/about/)。这里借鉴的是技术思路、色彩和构图方向；当前交付为可运行的第一版立体像素演出。

### 运行

1. 在 Godot 打开本项目，按 **F5**，从首页选择 **「折痕与歪楼 · 新剧情漫画人生」**。
2. 向下阅读至当前事件，点击画面中标记的人物、道具，或下方的 **「◇ 观察」类按钮**，观看靠近、查看或对话动作。
3. 观察结束会显示补充发现。继续用原有选项决定主角怎么做，然后阅读随机后果。
4. 特殊事件出现 **「重播特别镜头」** 和 **「跳过镜头」**；两者都不会替玩家提交剧情选择。
5. 保存书签可保留当前人生及已经完成的观察。继续旧书签时，会补上新的展示字段。

独立预览：打开 [scenes/PixelStageLab.tscn](../scenes/PixelStageLab.tscn)，按 **F6**。预览台提供上一场、下一场、场景互动、重播 CG、跳过 CG；覆盖出生、停电、橡皮、试演、离家、入职、体检、相册和长椅九个示例。此预览使用独立的内存剧情，不写正式游戏书签。

## 人物、空间与色彩

人物是原生 `Node3D` 关节配合块状网格组成的体素角色。主角按年龄调整身高和头身比例；新生儿采用卧姿与摇篮接触位置。主角与六类 NPC 共用身体结构、衣服明暗与配色规则，NPC 通过外衣、头发及配饰区分。走路、递接、阅读、打电话、挥手、击鼓、书写、坐下、点头和说话使用身体、手肘、膝盖与头部的连续姿态变化，主角行动后 NPC 可稍晚回应。

人物脚底以地面 `y = 0` 为基准；走路修正支撑脚位置。拿取、递交与阅读道具使用手部锚点，舞台负责角色在世界中的移动。婴儿不会因同一条走路指令变成站立成人。减少动态模式会降低角色动作幅度并停用自动镜头运动。

| 场景 | 主要空间细节 |
| --- | --- |
| 家庭 `home` | 深窗台、窗帘、沙发、靠垫、书架、台灯、照片与地毯 |
| 教室 `classroom` | 黑板与粉笔痕、前后排桌椅、书本、时钟与窗边植物 |
| 办公室 `office` | 显示器、键盘、杯子、工位椅、文件柜、告示与盆栽 |
| 医院 `hospital` | 床架、床垫、护栏、折叠帘、医生桌面与报告 |
| 公园 `park` | 路径、长椅、树冠、围栏、远处建筑、路灯与前景花坛 |

墙、地板和家具均有厚度。场景中心留出角色与交互道具的位置；前景植物、中景人物、后景家具与窗户形成深度。地砖合为一个 `MultiMesh`，五种环境分别使用约 59–83 个几何实例，不含人物与事件道具。

配色以 **墨青、灰绿、暖琥珀、赤陶** 为主：

| 用途 | 基准色 | 作用 |
| --- | --- | --- |
| 墨青 | `#172e38` / `#284750` | 轮廓、阴影、墙脚和远景，维持结构可读性 |
| 灰绿 | `#718c87` / `#53766f` | 墙面、家具和中景，统一人物与环境 |
| 暖琥珀 | `#efbd76` / `#ffe2a0` | 灯光、窗边亮部和互动提示，引导注意力 |
| 赤陶 | `#bc6652` | 小面积衣物、布料与故事道具，形成情绪重点 |
| 纸色 | `#dddbc3` | 书页、病床与浅色细节，衔接漫画阅读体验 |

`day`、`night`、`stage`、`quiet` 四种变体分别调整墙地颜色、环境光和局部灯能量。斜向方向光提供投影，局部暖灯给道具与人物增加明暗层次。采用 Compatibility 渲染器支持的光照；像素感来自有限分辨率的实际 3D 渲染与清晰放大。

## 31 个事件的可选互动

[pixel_story_direction.gd](../scripts/pixel_story_direction.gd) 为 **25 个日常事件与 6 个特殊事件**分别配置观察入口，共 31 个。例如：

- 橡皮事件：靠近观察切口和包装纸，再决定是否借出。
- 停电事件：试一试手指与光源的距离，发现影子的变化。
- 舞台事件：轻敲试音，得到同学回应，再决定是否表演。
- 体检事件：请医生解释圈出的项目，再决定下一步。
- 长椅事件：走近空位，观察对方挪开袋子的动作，再决定是否坐下。

互动的节奏借鉴在场景中接近人物、查看物件、获得补充信息的方式。当前每个事件提供一个约 3.6 秒的可选观察动作，使用「靠近 → 动作 → 对方回应／发现」的流程。观察会保存完成标记，并显示补充文字；它不消耗事件、结果、寿命等随机流，也不替代主选项或改变已经提交的后果。

只有当前尚未选择的事件允许新观察。已完成观察不能重复结算；历史页面仍可阅读。玩家可以直接选主选项，观察不是推进剧情的门槛。

## 8 个特殊事件，16 段实时 CG

[pixel_cg.json](../data/pixel_cg.json) 为以下 8 个事件分别配置开场与结果镜头，共 **16 段**，单段约 **6.8–9.6 秒**。

| 事件 | 开场镜头 | 结果镜头 |
| --- | --- | --- |
| LC01 出生 | 第一次握住世界 | 这间屋子学会了等待 |
| LC03 停电 | 今晚，太阳轮班 | 黑暗里有了形状 |
| LC09 舞台 | 第一拍之前 | 灯还亮着 |
| LC11 离家 | 门内的重量 | 带走一点家的颜色 |
| LC18 体检 | 红圈之外 | 下一步，还有空白 |
| LC20 旧钥匙 | 旧钥匙，新房间 | 声音留下的房间 |
| LC23 相册 | 照片外面的人 | 这一页也曾是今天 |
| RX02 确诊后的谈话 | 请再说慢一点 | 把下一步写下来 |

这里的 CG 是 **Godot 实时场景中的专门镜头演出**：相机位置、注视点和取景大小按时间平滑过渡，结合角色动作与该事件的光色。它们使用本次建立的体素角色和微缩环境，属于可交互的实时过场。结果镜头保留玩家已经提交的动作，镜头不会补选、推翻结果或生成另一条结局。

镜头正常结束后约 0.65 秒回到阅读构图，也可直接跳过。重播只重放演出，不重新抽取剧情。首次看到新特殊分镜时可自动播放；旧书签补入的镜头标记为已看，避免读档后连续自动重播历史。

## 滚动性能与存档

每个正在显示的分镜拥有独立 `SubViewport` 和 3D 世界，全局最多保留 **4 个活动视口**。分镜离开滚动可见范围后立即暂停绘制，持续离屏约 **0.35 秒**后释放世界；滚回时重建场景，并恢复观察状态。视口内部宽度按显示尺寸限制在 **最多 320 像素，以整数倍清晰放大**，高度随画面比例调整，关闭 3D 多重采样。

正式书签继续使用 `user://life_comic_v1.save`。人物对白版旧页面在读取时补充 `presentation`、场景色彩、互动与 CG 字段，保留原文字、动作、主选择和随机状态；更早的混排文本先经过既有的对白／旁白整理。观察完成与 CG 完成标记跟随分镜保存，重放过程不消耗人生随机数。读取失败时保留原书签，并关闭覆盖保存。

## 模块与验证入口

| 文件 | 职责 |
| --- | --- |
| [pixel_actor_3d.gd](../scripts/pixel_actor_3d.gd) | 年龄体型、NPC 形象、关节姿态、表情与手部锚点 |
| [pixel_environment_3d.gd](../scripts/pixel_environment_3d.gd) | 五种立体布景、配色、光照和地面 |
| [pixel_stage_view.gd](../scripts/pixel_stage_view.gd) | 小视口、走位、道具、观察、镜头和离屏释放 |
| [pixel_story_direction.gd](../scripts/pixel_story_direction.gd) | 31 个观察动作与特殊镜头查询 |
| [pixel_cg.json](../data/pixel_cg.json) | 16 段镜头时间线与开场／结果约束 |
| [life_comic_pages.gd](../scripts/life_comic_pages.gd) | 新剧情分镜接入和旧页面迁移 |
| [life_comic_reader.gd](../scripts/life_comic_reader.gd) | 观察／重播／跳过控件、剧情选择与书签保存 |

回归入口包括 `test/pixel_actor_3d_smoke.gd`、`test/pixel_stage_smoke.gd` 和 `test/pixel_reader_smoke.gd`。它们分别检查关节动作和脚底位置、真实视口及离屏释放、阅读器控件及磁盘书签。运行方式例如：

```text
godot --headless --path . --script res://test/pixel_actor_3d_smoke.gd
godot --headless --path . --script res://test/pixel_stage_smoke.gd
godot --headless --path . --script res://test/pixel_reader_smoke.gd
```

渲染效果另用 Compatibility 实际画面检查；无图形模式的通过只说明逻辑与资源可用，不能替代对遮挡、曝光和窄屏阅读的目视检查。
